# Walkthrough notebooks

The notebooks are intentionally small enough to run on a laptop and are saved
with outputs after verification.

1. `01_from_gate_to_swappy.ipynb` follows the model from a single gate to the
   four transport regimes.
2. `02_circular_moment_and_reproduction.ipynb` follows the analysis from local
   measurements to the circular moment, archived static data, and a seeded
   phase scan.

From the repository root:

```bash
make notebooks
```

The paper-scale command is shown but not launched inside a notebook.
